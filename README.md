# 🌻 Regalo de Flores Amarillas para Jhen (21 de Septiembre) ✨

Un regalo digital interactivo inspirado en la tradición de las **Flores Amarillas del 21 de septiembre**, la atmósfera visual y musical de **Kimi no Na wa (Your Name)**, una paleta estética con el color **Glauco** (`#5B8A8C`) y evolución botánica reactiva a puntuación.

---

## 🌐 Cómo publicarlo en GitHub Pages (Paso a Paso)

El repositorio local ya está inicializado y con todos los archivos guardados en la rama `main`. Para ponerlo en línea con tu propia cuenta de GitHub:

### Paso 1: Crear el repositorio en GitHub
1. Ingresa a **[github.com/new](https://github.com/new)**.
2. Nombra tu repositorio (por ejemplo: `flores-amarillas` o `flores-para-jhen`).
3. Asegúrate de marcarlo como **Public** (Público).
4. **NO** marques "Add a README file" (ya lo tenemos creado aquí).
5. Haz clic en **Create repository**.

### Paso 2: Vincular y subir desde tu Mac
En tu terminal, copia y pega estos comandos (reemplazando `TU_USUARIO` por tu nombre de usuario de GitHub):

```bash
cd /Users/angel/.gemini/antigravity/scratch/flores-amarillas
git remote add origin https://github.com/TU_USUARIO/flores-amarillas.git
git push -u origin main
```

*(Si GitHub te solicita contraseña, utiliza tu Personal Access Token o inicia sesión a través del navegador/Keychain de macOS).*

### Paso 3: Activar GitHub Pages para tener tu LINK
1. En tu repositorio en GitHub, ve a la pestaña **Settings** (Configuración) en la parte superior.
2. En el menú de la izquierda, haz clic en **Pages**.
3. En la sección **Branch**, selecciona `main` y la carpeta `/(root)`.
4. Haz clic en **Save** (Guardar).
5. En unos segundos, GitHub te dará tu enlace oficial:
   👉 **`https://TU_USUARIO.github.io/flores-amarillas/`**

## ⚡ Alternativa Ultrarrápida: Netlify Drop (En 15 segundos sin terminal)
Si quieres un link público de inmediato sin configurar repositorios:
1. Abre **[app.netlify.com/drop](https://app.netlify.com/drop)** en tu navegador.
2. Abre la carpeta en tu Mac:
   ```bash
   open /Users/angel/.gemini/antigravity/scratch/flores-amarillas
   ```
3. Arrastra la carpeta completa al recuadro de Netlify Drop.
4. En 10 segundos tendrás un link listo como `https://flores-jhen.netlify.app`.
